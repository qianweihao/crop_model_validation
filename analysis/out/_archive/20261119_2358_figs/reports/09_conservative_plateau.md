## 1. 为什么改这一项

|---|---|---|---|---|
| A1 | 3.07 | 3.06 | 2.92 | −4.7% |
| A2B1 | 3.33 | 3.35 | 3.24 | −2.7% |
| A2B2 | 3.45 | 3.40 | 3.38 | −2.2% |
| A3B1 | 3.52 | 3.53 | 3.42 | −2.8% |
| A3B2 | 3.55 | 3.54 | 3.51 | **−0.9%** |
| A4B1 | 3.24 | 3.09 | 3.15 | −2.9% |
| A4B2 | 3.41 | 3.29 | 3.11 | −8.7% |
| A5B1 | 3.11 | 2.99 | 3.10 | **−0.5%** |
| A5B2 | 3.11 | 2.96 | 2.92 | −6.2% |
| **均值** | | | | **−3.2%** |

**15 天只降 3.2%**，是真实存在的平台期。原模拟同期衰减 −8.1%。

## 2. 参数扫描

`SenescenceAcceleration` 是 APSIM 玉米叶龄组里**唯一**可调的衰老参数（已验证 `Lag`、
`SenescenceDuration`、`GrowthDuration` 在该版本不存在）。单点扫描（全部 9 小区）：

| 配置 | LAI RMSE | LAI 偏差 | 平台期 | 产量 RRMSE | 产量偏差 | 季末衰减 |
|---|---|---|---|---|---|---|
| sen = 0.33（原） | 0.376 | −0.068 | −8.06% | 8.98% | +3.69% | −45% |
| **sen = 0.20（采用）** | **0.343** | **−0.033** | **−5.24%** | **8.47%** | **+3.37%** | **−29%** |
| sen = 0.15 | 0.331 | −0.018 | −4.06% | 8.29% | +3.22% | −23% |
| sen = 0.10 | 0.321 | −0.003 | −2.84% | 8.14% | +3.04% | −16% |

**0.20 是取舍点**：平台期已接近实测（−5.2% vs −3.2%），同时保留足够的后期衰减。

---

## 3. 一个必须说明的结构性限制

**“平台期精确吻合”和“季末衰减 50–70%”无法同时满足。**

- 拟合平台期需要 sen ≈ 0.12 → 季末只衰减 16%，收获时 LAI 仍 2.9（不真实）
- 要 50–70% 季末衰减需要 sen ≈ 0.4–0.5 → 平台期变成 −11%（比实测陡 3 倍）

原因是 APSIM 玉米叶龄组的衰老只有**一个恒定加速度**，没有“延迟启动”通道，
所以做不出“先平后陡”的曲线形状。

> 另需注意：**实测叶面积只观测到 08-29**，此后到收获（10-08）无观测。
> 因此“典型玉米季末衰减 50–70%”是文献假设，不是本试验数据。
> 真实约束仅为 08-14 → 08-29 这 15 天。

### 5.1 氮胁迫图已取消

原拟的 NNI（氮营养指数）逐小区图**已不再作为正式图件**。原因：
本版本 APSIM 不提供 NNI 变量（`Maize.Nitrogen` 节点不存在），
`Photosynthesis.FN` 又恒为 1.0；事后用 Plénet & Lemaire (2000) 临界氮稀释曲线
算出的 NNI 在**全部小区都 < 1**，容易被误读为"所有处理都受氮胁迫"。
该指标只能反映小区之间的相对高低（A1 0.722 最低，施氮小区 0.77–0.81），
信息已由 `C4/L4` 的产量与生物量氮响应曲线替代表达。

## 6. 同批扫描中确认无效或不可用的参数

| 参数 | 结论 |
|---|---|
| `StructuralFraction` 0.827 → 0.98 | LAI 仅变 0.0005，**完全无效**（叶面积由 MaxArea 上限决定，不由叶质量决定） |
| `MaxArea.Skewness` ±0.6 | 超出允许范围，仅 0.001 附近可写 |
| `LargestLeafPosition` 0.65 → 0.80 | 只降低峰值幅度，**无法推迟峰值日期**；峰值被物候固定在 08-03 |
| `Lag` / `SenescenceDuration` / `GrowthDuration` / `ShadeInducedSenRate` | 该版本不存在 |
| `Photosynthesis.FN` | 硬编码常量 1.0，不可用于调节 |

## 7. 未采纳的激进方案（备查）

需求若改为"优先修生物量"，可考虑 `sen=0.20 + RUE=2.70 + LLP=0.690 + MaximumGrainsPerCob×0.85`：

- LAI RMSE 可降到 **0.268**
- 生物量偏差由 −19% 改善到 **−12%**
- 代价：产量偏差由 +3.7% 变成约 −3%；RUE 2.70 高出 APSIM 玉米默认值 2.0

不采用的理由：RUE 抬高会同时放大低氮小区（A1、A2B1）的生物量与产量，而高氮端仍缺 13–25%，
属于"用尺度误差掩盖氮响应误差"。详见 `RESULTS.md` §6。
