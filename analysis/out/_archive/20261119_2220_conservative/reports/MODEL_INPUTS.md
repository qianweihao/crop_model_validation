### 5.2 水力参数（各小区不同，取自实测 SAT / FC）

| 试验 | AWC (mm) | 有效孔隙 (mm) | DUL 表层 | LL15 | SAT | BD | 有机碳 % |
|---|---|---|---|---|---|---|---|
| SD_SF | 306–357 | 119–160 | 0.314–0.346 | **0.137–0.151** | 0.393–0.431 | 1.51–1.60 | 1.096 |
| XX_SF | 208–300 | **55–258** | 0.214–0.308 | 0.126–0.144 | 0.303–0.451 | 1.45–1.60 | 1.346 |
| XX_IRR | 208–237 | 147–190 | 0.213–0.244 | 0.128–0.148 | 0.313–0.326 | 1.60 | 1.346 |

**参数推导方式：**

| 参数 | 来源 |
|---|---|
| `DUL` | **实测田间持水量**（体积 %） |
| `SAT` | **实测饱和含水量**（体积 %） |
| `LL15` | **Saxton-Rawls (2006) 质地传递函数**，由实测砂粒/黏粒/有机质推算（详见 MODEL_SUMMARY §1.3.1） |
| `AirDry` | 0.5 × LL15 |
| `BD` | (1 − SAT) × 2.65，截断于 [1.15, 1.60] |
| `KS` | 质地经验值，按层递减 [40, 30, 20, 12, 8, 5] mm/d |
| `Carbon` | OM(%) ÷ 1.724（德州 OM 1.89%，新乡 OM 2.32%） |
| `FBiom / FInert` | [0.04,0.03,0.02,0.01,0.01,0.01] / [0.40,0.60,0.80,0.95,1.00,1.00] |
| `SWCON` | [0.55, 0.45, 0.35, 0.30, 0.25, 0.20] |
| `pH` | 德州 8.16，新乡 8.39 |

**示例（SD_SF_A1，各层相同）：** LL15 **0.1418** / DUL 0.3261 / SAT 0.4109 / BD 1.561 / 砂粒 30.9% / 黏粒 21.5%

**LL15 推导公式（Saxton-Rawls 2006）：**
```
θ₁₅₀₀ = −0.024·S + 0.487·C + 0.006·OM + 0.005·(S·OM)
        − 0.013·(C·OM) + 0.068·(S·C) + 0.031
```
校验：砂土 4.1%（文献 4–6%）、壤土 13.5%（12–15%）、粉砂壤土 11.4%（10–13%）、
黏土 30.0%（30–35%），全部吻合。同套参数预测 FC=30.7%，实测 31.4–34.6%（偏差 +7.8%）。
