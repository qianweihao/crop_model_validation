## 6. 品种参数（乐农87，基于 `990002`）

**最终方案（A，2026-11 定稿）**：

| 参数 | 含义 | 起始值 | **定稿值** | 标定目标 |
|---|---|---|---|---|
| `P1` | 出苗→苗期结束热时（>8 ℃） | 200 | **250** | 最终叶数 20（实测 20）+ 吐丝 08-10 |
| `P2` | 光周期敏感性 | 0.30 | **0.30** | 未标定 |
| `P5` | 吐丝→生理成熟热时 | 800 | **880** | 成熟期 |
| `G2` | 单株最大粒数 | 700 | **1300** | 产量 + 粒数 |
| `G3` | 灌浆期单粒增长速率 mg/d | 8.5 | **6.8** | 产量 + 单粒重 |
| `PHINT` | 出叶间隔热时 | 38.9 | **51** | 出叶进程（可见叶误差 −1.8 d） |

标定过程：

1. 原三阶段网格标定（`s03_calibrate.py`，116 次评估）得到
   `P1 235 / P5 880 / G3 6.0 / PHINT 60`：产量 RRMSE 3.70%、生物量 −10.9%，
   但**最终叶数只有 17 片**（实测 20）、出叶偏早。
2. 2026-11 按"叶数 20 + 吐丝 08-10~08-12 + 产量生物量平衡"重新搜索
   （`s13_phint.py`、`s14_sd_sf_phint55.py`），得**方案 A**：

| 指标 | 方案 A | 原标定 |
|---|---|---|
| 最终叶数 | **20** | 17 |
| 吐丝（ADAT = 75% silking） | **08-10** | 08-12 |
| 成熟 | 10-03 | 10-08 |
| 产量 RRMSE / 偏差 | 5.16% / +1.52% | **3.70% / +0.11%** |
| 生物量偏差 | **−7.65%** | −10.9% |
| LAI RMSE | 0.697 | **0.436** |
| 可见叶出叶误差 | **−1.8 d** | −8.0 d（展开叶口径） |

取舍说明见 [`DSSAT_MY73_QUESTIONS.md`](DSSAT_MY73_QUESTIONS.md) 附四、附五：
CERES 里叶数、出叶时间、吐雄期由 `P1/PHINT` 一个比值绑死，补叶数必然
缩短灌浆期（成熟早 5 天）并抬高前期 LAI（RMSE 0.44 → 0.70）。

## 7. 哪些是实测、哪些是标定

| 类别 | 参数 | 来源 |
|---|---|---|
| **实测** | SDUL、SSAT、砂粒/黏粒、耕层有机质、密度、播期、施肥/灌溉日期与用量、LAI/生物量/产量 | 田间记录 |
| **传递函数** | `SLLL` | Saxton-Rawls (2006)，由砂粒/黏粒/有机质推算 |
| **由实测推导** | `SBDM`=(1−SSAT)×2.65 | 截断 [1.15, 1.60] |
| **假设（无实测）** | 初始含水量 = 田间持水量；初始 NH₄ 11 kg N/ha；氮层间分配权重；深层 SLOC 剖面；`SLU1/SLDR/SLRO`；播深 4 cm；行距 60 cm | 见 §3、§4 |
| **标定** | `P1`、`P5`、`PHINT`、`G2`、`G3`、**初始 NO₃ 比例 0.24** | §6 |
| **DSSAT 默认** | 物种参数（`MZCER048.SPE`）、生态型 `IB0001`、SOM/蒸发/入渗方法参数 | 未改动 |

> 初始 NO₃ 与深层 SLOC 二者都只影响氮供应，**不可独立识别**：
> 均匀 1.1% 有机碳时矿化约 220 kg N/ha，任何施氮水平都不缺氮；
> 递减剖面下矿化降到 82 kg N/ha，A1 才出现氮胁迫。详见 `DSSAT_VALIDATION.md` §3.1。
