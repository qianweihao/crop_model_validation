| 播深 / 行距 | 4 cm / 60 cm | 4 cm / 60 cm | 4 cm / 60 cm |

### 5.2 施肥与灌溉

| | SD_SF | XX_SF | SD_MY73 |
|---|---|---|---|
| 施氮 | 0–254 kg N/ha，4–7 次 | 0–276 kg N/ha，5 次 | **不模拟氮限制**（`NITRO=N`） |
| 肥料 | 尿素 `FE005`，5 cm | 尿素 `FE005`，5 cm | 尿素 `FE005`，5 cm |
| 灌溉 | 62.6–86.0 mm，5–8 次 | 33.9–97.8 mm，3–6 次 | **100 mm，4 次（假设）** |
| 灌水类型（记录） | 水肥一体化滴灌 + 大水 | 水肥一体化滴灌 + 大水 | 无记录 |

> `SD_MY73` 的 `NITRO=N`：该试验没有施肥记录，但实测 12.2 t/ha 说明氮供应充足；
> 若按假设的 270 kg N/ha 模拟，会出现 `NSTD` 峰值 0.44 的假氮胁迫。
> 关闭后不输出 `NSTD`/`NUCM`。

**施肥方式 `FACD` 按记录自动判定**（`dssat_common.FACD_MODE="auto"`）：

| 情形 | 代码 | 含义 |
|---|---|---|
| 施肥日与灌溉日重合 | `AP005` | 随灌溉水施用（水肥一体化） |
| 播前基肥 | `AP008` | **种肥同播**（施于种子处） |
| 其余 | `AP001` | 表施不混土 |

> 这一步很关键：原来全部按 `AP001` 表施尿素，DSSAT 会算大量氨挥发，
> 吸氮只有 154–168 kg N/ha；改成 `AP005` 后升到 197–202 kg N/ha，生物量偏差从 −7.7% 收到 −2.8%
> （2026-11 氮响应重标后为 −3.3%）。

**灌溉水利用系数 0.90**：记录的是毛水量，写入 DSSAT 的是 **0.90 × 毛水量**（有效水量）。
DSSAT 的 `EFIR` 字段在报告式灌溉（`IRRIG=R`）下不生效（实测 1.0 → 0.5 结果只差 0.2%），
所以系数直接乘在每次灌水量上（`IRRIG_EFFICIENCY = 0.90`）。

**灌溉方式 `IROP` 统一写 `IR001`（沟灌）**：DSSAT 只用日期 + 水量，
`IR001`（沟灌）和 `IR005`（滴灌）**模拟结果完全一样**（实测验证），
所以灌溉方法只作标签，不进物理过程。

> 滴灌的湿润体、滴头流量、局部根区、氮随水迁移都没有建模。

> 整数化损失：`FAMN`/`IRVAL` 是整数字段，写入值比记录值低 0–7%
> （逐小区对照见 `out/<trial>/sim/management_schedule.csv`）。

- `CTCNP1` 只对 SD_SF 提到 2.00（新乡的氮响应已经对上，不需要改），
  使模型 N 饱和点从 110 提到 168 kg N/ha（田间实测 177）。见 `DSSAT_RESULTS.md` §7.10。

## 7. 参数来源分类

| 类别 | 参数 |
|---|---|
| **实测** | SDUL/SSAT/质地、耕层有机碳、密度、播期、施肥与灌溉日期和用量、LAI/生物量/产量、叶期 |
| **传递函数** | `SLLL`（Saxton-Rawls 2006）、`SBDM` |
| **假设** | 初始含水量 = 田间持水量；初始 NH₄ 11 kg N/ha；氮层间分配；深层 SLOC 形状；`SLU1/SLDR/SLRO`；播深 4 cm；行距 60 cm；SD_MY73 的全部管理 |
| **标定** | `P1/P5/G3/PHINT`（逐试验）、初始 NO₃ 比例（**0.65** / 0.55）、SLOC 缩放（1.0 / 0.7 / 1.0）、`CTCNP1`（德州 **2.00**，新乡默认 1.52） |
| **DSSAT 默认** | 物种参数（除 PARSR）、生态型、SOM/蒸发/入渗方法参数 |

## 9. 可移植的文件包

`out/<trial>/bundle/` 是自包含的一套，别人拿走即可运行：

```
<plot>.MZX            每个小区一份 FileX（文件名 ≤8 字符是 DSSAT 硬约束）
SOIL.SOL              该试验全部土壤剖面合并
Weather/<INSI>2601.WTH
MZCER048.CUL          品种参数（含标定后的品种行）
MZCER048.SPE / .ECO   物种 / 生态型
_support/             StandardData / Soil / Pest
run.py / run.bat      一键运行
```

```bash
cp -r bundle C:/dssat      # 必须放到短路径，见下
cd C:/dssat
python run.py --exe <dscsm048.exe>
```

**两个坑**：
1. DSSAT 的路径变量定长，**超过约 60 字符会静默截断**（报 `File not found ... SIMCDE`）。
2. FileX 文件名基名 **≤8 字符**，否则报 `IPEXP`。

GUI 用户：`.WTH` 放 `Weather\`、`SOIL.SOL` 并入 `Soil\`、品种行加进 `Genotype\MZCER048.CUL`，
再用 XBuild 打开 `.MZX`。
